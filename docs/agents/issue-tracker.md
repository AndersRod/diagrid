# Issue Tracker

Work for this repository is tracked in an external issue tracker. The tracker isn't referenced from this repository on purpose.

## For agents

- How to reach the tracker (workspace, team, project, statuses) is configured per machine in `CLAUDE.local.md`. That file is gitignored and never committed.
- If no tracker configuration is available, work without one. Don't invent an issue workflow.
- Never put tracker IDs, URLs or branch names generated by the tracker into git. That covers branch names, commit messages, PR titles and descriptions, code comments and docs. Branches follow the naming rules in `AGENTS.md`.
- Links between work and code go one way only: the tracker may point at branches and PRs, but the repository never points back at the tracker.
